# Admin Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dashboard's separate CMS and library links with one protected Admin hub that offers both destinations.

**Architecture:** The existing server-derived `canAccessContent` prop controls a single `/admin` sidebar entry. A new server-rendered `/admin` route calls the existing access guard and renders links to the library and Payload CMS.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind CSS v4, Lucide React, ESLint, TypeScript.

## Global Constraints

- Keep `requireLibraryAccess` as the single authorization policy.
- Retain the dashboard's monochrome, square-corner design system.
- Do not alter unrelated Payload, Stripe, generated, or scratch worktree changes.
