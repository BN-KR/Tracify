Langfuse is an open‑source AI engineering platform to build, monitor, and improve LLM apps and agents.

What you can use it for

  • Observability & tracing: Capture every request (prompts, responses, tool calls, token usage, latency), analyze sessions, agent graphs, dashboards, and alerts
    • Docs: https://langfuse.com/docs/observability/overview
  • Prompt management: Version, label/deploy, test in a playground, and link prompts to traces
    • Docs: https://langfuse.com/docs/prompt-management/overview
  • Evaluation: Score quality via LLM-as-a-judge, code evaluators, user feedback; run datasets and experiments to compare prompts/models
    • Docs: https://langfuse.com/docs/evaluation/overview
  • Platform & APIs: SDKs (Python/JS), Public API, CLI, exports, enterprise security, self-hosting
    • Overview: https://langfuse.com/docs

Minimal, runnable examples

  • Trace a generation (Python)

    • Quickstart: https://langfuse.com/docs/observability/get-started
    • Example:
      • pip install langfuse
      • In code:
        • from langfuse import Langfuse
        • lf = Langfuse()
        • with lf.trace(name="answer_question") as t: with t.generation(name="openai_call", input="What is Langfuse?", model="gpt-4o", usage={"input": 10, "output": 50}) as g: g.output = "Langfuse is an open‑source AI engineering platform..."

  • Manage a prompt and use it (JS/TS)

    • Prompt mgmt: https://langfuse.com/docs/prompt-management/get-started
    • Example:
      • npm i langfuse
      • In code:
        • import { Langfuse } from "langfuse"
        • const lf = new Langfuse()
        • const prompt = await lf.getPrompt("support_reply", { label: "production" })
        • const rendered = prompt.compile({ question: "What is Langfuse?" })

  • Add a custom quality score (Python)

    • Scores API: https://langfuse.com/docs/evaluation/scores/overview
    • Example:
      • from langfuse import Langfuse
