# Workflow

1. **Initialization:**
   - Review `memory.md` and `scratchpad.md`.
   - Identify the current active task in `tasks/current.md`.

2. **Execution:**
   - Execute the task.
   - Utilize provided tools (`view_file`, `replace_file_content`, etc.).
   - If blocked, document in `tasks/current.md` and update `scratchpad.md` with hypotheses.

3. **Finalization:**
   - Update `tasks/completed.md` and remove from `tasks/current.md`.
   - Clear outdated info from `scratchpad.md`.
   - Update `docs/decisions.md` and `memory.md` if significant architectural or strategic changes occurred.
